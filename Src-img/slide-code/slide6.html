GoSMS Integration

This is NOT just a form submission feature. It involves complex financial mapping, unstable external dependencies, and strict atomicity requirements.

Multi-Entity Allocation

Financial Mapping Risk

A single Brand selection may map to multiple Outlets, which belong to different financial Companies.

Critical Risks:

  • • Credits allocated per company, not brand
  • • Mapping inconsistency
  • • Aggregation errors

External Dependency

QuickBooks API

Reliance on a third-party system (QuickBooks) for invoice generation introduces network and logic instability.

Critical Risks:

  • • Network timeouts & latency
  • • Duplicate invoice creation
  • • Partial success states

Transactional Integrity

Atomicity Requirement

Quotation generation and SMS crediting must behave as a single atomic unit. Failure in one must roll back the other.

Critical Risks:

  • • "Zombie" credits (No invoice)
  • • Invoice without credits
  • • Data integrity corruption
